# 🦆 Tecelão Musical: A Aventura Musical de Brusque

O **Tecelão Musical** é um jogo educativo rítmico desenvolvido para crianças de 4 a 5 anos da rede municipal de ensino de Brusque. O projeto integra tecnologia e valorização cultural, explorando a história, os sons e as tradições locais de forma lúdica e acessível.

🔗 **Link para o Jogo:** [Acesse aqui o Tecelão Musical](https://nicolybb.github.io/tecelao-musical/)

## 🎮 O Jogo

O "Tecelão Musical" combina mecânicas de ritmo com aprendizado cultural:

* **Fase de Ritmo:** A criança deve pressionar a tecla `ESPAÇO` no momento exato em que a bolinha atinge o alvo. Cada acerto revela gradualmente uma imagem histórica ou cultural da cidade.
* **Desafio Cultural:** Após revelar a imagem, surge uma pergunta interativa (em **CAIXA ALTA** para facilitar a leitura) sobre temas de Brusque, como a Fenarreco, a tecelagem e a fauna local.

## ✨ Funcionalidades Principais

* **Velocidade Dinâmica:** O jogo se adapta ao desempenho do aluno (Lento, Normal ou Rápido).
* **Acessibilidade:** Suporte de áudio para leitura de perguntas e textos em letras bastão.
* **Representatividade:** Design inclusivo que reflete a diversidade da comunidade escolar.

## 🚀 Tecnologias Utilizadas

Para garantir a compatibilidade com os Chromebooks das escolas, utilizamos:

* **HTML5**
* **CSS3** (Variáveis customizadas e Design Responsivo)
* **JavaScript** (Vanilla)
* **Particles.js** (Efeitos visuais da tela inicial)
